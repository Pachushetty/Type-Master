# ⌨️ Type Master – Typing Speed Test

A modern, interactive, and personalized **Typing Speed Test web application** built with **Flask, HTML, CSS, JavaScript, and SQLite**.

Type Master helps users improve their typing speed and accuracy through timed typing tests, personalized statistics, challenges, performance tracking, and a private user dashboard.

---

## 🚀 Features

### ⌨️ Typing Test

- 📝 Random typing passages
- ⏱ Multiple time modes:
  - 15 seconds
  - 30 seconds
  - 60 seconds
  - 120 seconds
- 🎯 Real-time character highlighting
  - 🟢 Correct characters
  - 🔴 Incorrect characters
- 📊 Live WPM
- 🎯 Live accuracy
- ❌ Error tracking
- 📈 Typing progress indicator
- ⏳ Countdown timer
- 🔄 Retry the same passage
- 🆕 Start a new passage
- ⌨️ Keyboard visualization
- ⚡ Timer starts automatically when typing begins

---

## 🎮 Typing Modes

### Normal Mode
A standard typing speed test that measures your WPM, accuracy, and errors.

### 🎯 Accuracy Challenge
Focuses on typing correctly with fewer mistakes.

### ⚡ Speed Challenge
Focuses on achieving the highest possible WPM within the selected time.

---

## 📚 Difficulty Levels

Choose the difficulty that matches your skill level:

- 🟢 Easy
- 🟡 Medium
- 🟠 Hard
- 🔴 Expert

Each level provides different typing passages and difficulty.

---

## 👤 User Accounts

Users can create their own account and securely log in.

### Authentication Features

- 📝 Create an account
- 🔐 Secure login
- 🔒 Password hashing
- 🚪 Logout
- 👤 Personalized user session
- 🔒 Private user statistics

Each user's typing results are stored separately.

---

# 📊 Personal Dashboard

The dashboard is available **only after login**.

Each user gets their own private dashboard.

### Dashboard includes:

- 🏆 Personal Best WPM

- 🎯 Average Accuracy
- 📝 Total Tests
- 🔥 Daily Practice Streak
- 📈 WPM Progress Chart
- 🎯 Accuracy Statistics
- 🏅 Personal Best
- 📝 Recent Typing Tests
